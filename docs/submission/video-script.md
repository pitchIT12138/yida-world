# 90 秒演示路线（2026-09-15 体验版）

0–18 秒：打开作品链接，直接拖动首屏 DLSS 原图的分隔线。放大到 2 倍，点击“移动局部”拖动，再切换并排。旁白：“这是一篇真实回答。保留作者原图，让读者自己观察区别。”

18–35 秒：点顶部“现金流”。选中一年，拖柱顶或输入该年金额，保留方案 A，再改变整条曲线的收入、支出或折现率。指出手动修改的年份有独立标记，可以撤销。4%为演示值，不是作者缺失的原文数字。

35–49 秒：点“人口与供养”。选原文年份，再改变人群数量，观察人形和供养比例；保存 A 后继续修改 B。明确这是情景实验，不是假装完整人口预测。

49–65 秒：进入近视故事，开门、靠近人影、切换人物与读者视角，再推进换衣后的画面。旁白：“相同空间里的可见信息不同，误认推动了故事。”不编造原文之外的结局。

65–78 秒：任选食物组成或 Redis。自由输入份数或请求数，展示连续变化；用复位回到原参数。说明形式由文章论点决定，宿主不按题材挑固定模板。

78–90 秒：点“完整原文”，再回到“互动阅读”，展示交互状态仍在。旁白：“17 篇内容可以直接阅读，原文、图片与历史保留。核心操作始终在前，其他操作沿原文展开。”

录制范围：公共阅读演示。真实 OAuth 授权与个人生成保存仍未完成最终验收，不录制模拟登录，不把暂停中的后台生产说成已上线自动更新。
