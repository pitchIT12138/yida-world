# 90 秒演示路线

0–12 秒：首页。旁白：很多回答，我们看过了，却还想亲手试一次。一答一世界让程序成为内容的一种表达。

12–35 秒：打开真实现金流回答，先看原文，再改变工时或折现率，展示可见变化；点击原文切换，说明作者原话始终保留。使用最终验收通过的版本录制。

35–52 秒：展示一篇不同类型的交互，如人口口径比较或叙事视角。让读者看到两种操作服务于不同的理解任务。

52–65 秒：打开设计讲解。旁白：模型还要解释为什么在这段文字旁放这个交互，读者可以回到证据，而不是只看一个热闹的小程序。

65–80 秒：展示讨论发现与交互新作。说明摘要用于发现，取得正文才进入生成与验收；首发由管理员触发更新。

80–90 秒：若真实 OAuth 已完成，展示登录后的个人作品；否则明确画面字幕“登录接入待配置”，不演示模拟登录。收束：从读一篇回答，到亲手理解一个世界。
