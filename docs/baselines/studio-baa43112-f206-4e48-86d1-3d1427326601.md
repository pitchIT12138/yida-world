# 你对中国老龄化的未来怎么看？

基线版本：session-repair-2026-09-14

## 整篇表达

把人口结构、年龄口径、制度人数与生产率分开操作，亲眼看见总量小变与供养关系大变。

结论处看人群重排 → 生育处推时间 → 三种口径处搭供养连线 → 人数处转移缴费者 → 生产率处填补产出缺口。

作者语气：原文保留；补充计算、示意与情景均在操作旁标注。

## 片段分工

### 同一百人，结构在移动

- 稳定 ID：population-crowd
- 位置：p-091eef03-36a7-4cef-9483-ca5564f4372c
- 形式：experience

表达任务：先比较相同人数的结构，再看绝对量，防止把2%的总量变化误当成养老压力的全部。

放在这里的理由：紧接对应原文：换句话说，十年以后大约每3个人就有1个60岁以上老人，每4个人就有1个65岁以上老人。

操作与反馈：点2035，再回2025；同一百个人形重新分组，人数指标同步。

实现约定：独立沙箱内 HTML、CSS 与 SVG；共享状态只经 world 协议。

验收：

- #y2035 → 2035：每100人中约33人年满60岁
- #reset → 2025：每100人中约23人年满60岁

代码指纹：505cb0caaa53e309073bb4b8eda81d18e96d6ff8d8280134e70b77d35157d279

### 把一个新生儿送到2035年

- 稳定 ID：birth-clock
- 位置：p-db3a04c5-c671-4827-8e60-ec04c6b6f503
- 形式：experience

表达任务：用出生年份推进解释时滞；儿童情景不会伪造2035劳动人口变化。

放在这里的理由：紧接对应原文：因为2026年出生的孩子到2035年仅9岁，期间的生育政策无法改变2035年的劳动力及退休人口，只能影响儿童数量。未来十年的养老问题已由现有年龄结构决定，即使TFR恢复至1.5也无法增加2035年的缴费人口。劳动力供给的改善需等到2045-2055年以后。

操作与反馈：切生育情景观察儿童数量，再拖动年份让2026新生儿走到16岁。

实现约定：独立沙箱内 HTML、CSS 与 SVG；共享状态只经 world 协议。

验收：

- #year → 2042年：16岁，已到16岁参照线
- #optimistic → 乐观情景 · 2035儿童 1.41 亿 / 总人口 13.87 亿

代码指纹：3975c3f30210625b4657c04a46bdaa06da8b6e4195039955d94b98a13d7bf6ac

### 谁在连向同一个领取者？

- 稳定 ID：support-lens
- 位置：p-d5457ad6-3932-4f0f-a826-329fd70bf2f8
- 形式：experience

表达任务：用一名分母对象和对应数量的连线，澄清支持比、抚养比与养老金参保口径。

放在这里的理由：紧接对应原文：约2.6名在职参保职工，对应1名领取职工养老金的退休人员。

操作与反馈：切换年龄或参保口径，再换年份；连线数量、标签和倒数计算一起变化。

实现约定：独立沙箱内 HTML、CSS 与 SVG；共享状态只经 world 协议。

验收：

- #future → 2035 · 15—64岁人口 / 65岁以上人口 = 2.75 : 1
- #insured → 2035 · 参保职工（中央情景） / 退休领取者 = 1.80 : 1

代码指纹：f179a08f7b73c2c494e5bee2587d5323cc8f83d2c55c93754371c692f2826910

### 把人移过缴费线

- 稳定 ID：pension-transfer
- 位置：p-e8f578db-a457-4b41-988e-8917a74afa23
- 形式：experience

表达任务：让相同总人数在两端转移，看到比率变化不是只给分子加人。

放在这里的理由：紧接对应原文：真正增长最快的是分母——退休人口，所以养老金系统的主要压力来自退休者增长速度与缴费者增长速度之间的差额。

操作与反馈：点击左移或右移，每步一千万人；点阵、两端人数和供养比同时改变。

实现约定：独立沙箱内 HTML、CSS 与 SVG；共享状态只经 world 协议。

验收：

- #move → 缴费 4.05 / 领取 2.10 亿 · 1.93 : 1
- #reset → 缴费 3.95 / 领取 2.20 亿 · 1.80 : 1

代码指纹：8deb3460e1707ea2d185e9c1222342c996f6648a5b9093e2c1b5878dd875959a

### 人数少了，每人多做多少？

- 稳定 ID：productivity-factory
- 位置：p-3bff9c32-4def-4325-8d92-6bd43fc67d60
- 形式：experience

表达任务：固定分配关系后，让生产率填补人口供养比下降留下的缺口。

放在这里的理由：紧接对应原文：本质上是 劳动人口人均生产率 创造的产出，在劳动者与退休者之间重新分配。所以如果一个劳动者2035年的产出比2025年高很多，那么即便供养比从2.6降到1.8，经济系统也并不一定不可持续。

操作与反馈：点刚好补齐，再手动调整增长率；2035产出条跨过或落后于基准线。

实现约定：独立沙箱内 HTML、CSS 与 SVG；共享状态只经 world 协议。

验收：

- #equal → 每名领取者对应产出指数：100.00（2025 = 100）
- #growth → 每名领取者对应产出指数：173.08（2025 = 100）
- #growth → 每名领取者对应产出指数：34.62（2025 = 100）
- #reset → 每名领取者对应产出指数：69.23（2025 = 100）

代码指纹：561e7ca2e785d75ec5cf3b9a4d76132f3c8cd62051185be077f8a4558c32d786
