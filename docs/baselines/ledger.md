# 买完房的第一个月，账本才刚刚开始。

基线版本：session-repair-2026-09-14

## 整篇表达

把月供拆成利息与本金，再按月消费现金储备，比较看似付得起与真实缓冲。

第一段推导月供 → 生活事件段按月记账；默认家庭与情景开支分开标记。

作者语气：原文保留；补充计算、示意与情景均在操作旁标注。

## 片段分工

### 每个月，同一笔月供分给谁

- 稳定 ID：mortgage-strips
- 位置：ledger-p0
- 形式：experience

表达任务：固定月供拆成两块可变面积，利息下降与本金上升一目了然。

放在这里的理由：紧接对应原文：这是一户虚构家庭的账本。每月税后收入 25,000 元，日常开支 10,000 元，另有 150,000 元现金储备。假设贷款 1,500,000 元，年利率 3%，期限 30 年，采用等额本息。

操作与反馈：拖动月份查看同一笔付款内部的变化，避免把利息当成每期固定。

实现约定：独立沙箱内 HTML、CSS 与 SVG；共享状态只经 world 协议。

验收：

- #reset → 月供 6324.06 元 · 第1期利息 3750.00 元

代码指纹：29916272f35ebdbdc71ffb67f849f65b0e20c549a93a5ff40c53ef66f800da3a

### 让生活继续一个月

- 稳定 ID：cash-reserve
- 位置：ledger-p2
- 形式：experience

表达任务：让每次生活事件真正扣减现金并留下明细，区分月度盈余与累计缓冲。

放在这里的理由：紧接对应原文：我想比较的不是哪种选择适合所有人，而是在同一组假设下，几种决定会怎样改变这户家庭的现金缓冲。所有数字都是演示假设，不代表真实家庭或当前市场报价。

操作与反馈：按月推进或添加一次性支出，现金条左右跨过零点，复位可重跑另一种选择。

实现约定：独立沙箱内 HTML、CSS 与 SVG；共享状态只经 world 协议。

验收：

- #lost → 第1月 · 现金 113675.94 元 · 缓冲 7.0 个月
- #reset → 第0月 · 现金 150000.00 元 · 缓冲 9.2 个月
