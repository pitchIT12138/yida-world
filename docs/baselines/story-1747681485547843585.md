# 近视眼勇闯恐怖游戏

基线版本：free-exploration-2026-09-15

## 整篇表达

通过楼层占用、门内场景和信息显隐，体验主人公的日常解释与读者危险知识之间的错位。

先在标题与原文短引后操作「一连串照顾，改变了正在发生的事」。推开门，探索人影；切换人物所见与读者已知。随后按“接着探索”回到对应原文中的其他交互；补充文字可收起，操作始终展示。完整原文保留全部段落与原图。

作者语气：原文保留；补充计算、示意与情景均在操作旁标注。

## 风格约定

- 配色：#2b202d、#eee3df、#963f5a
- 字体：系统中文字体；指标等宽数字；窄屏指标整段换行。
- 材质与留白：每篇由其论点或叙事情境决定画面，操作反馈就在原文对应位置。
- 动作：仅操作驱动；即时反馈；键盘、触摸和复位等价可用。
