# 近视眼勇闯恐怖游戏

## 整篇表达

沿故事中的误认比较人物可见信息与读者额外信息，让反差来自原文线索。

有限视野 → 房间选择的信息差 → 亲密称呼与恐怖身份的反差。

作者语气：保留原文语气，补充内容使用可核对的解释。

## 风格约定

- 配色：#7a506c、#f7eff5、#243b3b
- 字体：正文15px，数字使用表格数字，标题18–20px；窄屏保持标签与完整数值。
- 材质与留白：图示随正文展开，细线区分论点，控制区与结果在同一阅读位置。
- 动作：操作即时响应；动画由读者启动，可停止或复位。

## 设计决策

### 围绕问题安排操作

沿故事中的误认比较人物可见信息与读者额外信息，让反差来自原文线索。

取舍：减少无信息增量的装饰，保留能比较、计算和定位证据的反馈。

原文引述、补充计算和情景假设分别说明；缺失资料不补成确定事实。

取舍：对缺少明细的地方仅提供已有数据范围内的比较。
