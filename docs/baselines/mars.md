## 片段分工

### 谢邀发出了，地球还没收到

- 稳定 ID：light-post
- 位置：mars-p1
- 形式：experience

表达任务：信封位置对应实际光速计算，送达与回复不是同一状态。

放在这里的理由：紧接对应原文：为了讨论得具体，假设这次两地相距 2.25 亿千米，按每秒 299,792.458 千米计算单程延迟。现在，你在火星发出一句“谢邀”，地球上的人什么时候能看到？

操作与反馈：发送后推进5分钟或直接到送达时刻；换距离会重启情景，避免混用两条时间轴。

实现约定：独立沙箱内 HTML、CSS 与 SVG；共享状态只经 world 协议。

验收：

- #send → 消息正在去地球的路上
- #step → 消息正在去地球的路上
- #arrival → 地球已收到；回复正在路上
- #arrival → 回复已回到火星
- #reset → 待发送
