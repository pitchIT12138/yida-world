# 十年后，我换掉的不是一张桌子。

基线版本：session-repair-2026-09-14

## 整篇表达

把不同年份的桌面并置，翻开物件才看到原句；愿望的改变通过留下与移走的东西呈现。

2016愿望 → 2021物件增多 → 2026选择留下车票；每件物品关联原句。

作者语气：原文保留；补充计算、示意与情景均在操作旁标注。

## 风格约定

- 配色：#183a35、#f2f5ed、#d98b51
- 字体：系统中文字体；指标等宽数字；窄屏指标整段换行。
- 材质与留白：每篇由其论点或叙事情境决定画面，操作反馈就在原文对应位置。
- 动作：仅操作驱动；即时反馈；键盘、触摸和复位等价可用。

## 片段分工

### 十年都在这张桌上

- 稳定 ID：desk-archive
- 位置：desk-p2
- 形式：experience

表达任务：年份切换改变桌面上的实体与数量，物件打开对应原句，叙事比较建立在具体意象上。

放在这里的理由：紧接对应原文：2026 年，桌子还是那张桌子。我留下一张旅行车票，把“很厉害”改成“有时间认真生活”。这是一个虚构人物的片段，不是一份职业建议。

操作与反馈：在2021翻工牌和待办，再到2026翻车票；并置2016的愿望，观察物件与原句的变化。

实现约定：独立沙箱内 HTML、CSS 与 SVG；共享状态只经 world 协议。

验收：

- [data-object="2"] → 把每天填满，并不等于知道自己想去哪里。
- #y2026 → 2026 · 1件可翻看的物件
- [data-object="0"] → 有时间认真生活。
- #y2016 → 2016 · 1件可翻看的物件
