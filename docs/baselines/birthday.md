把“与你同生日”与“任意两人”放进同一个房间，用真实抽样对照不断增加的配对数量。

两种问题处连线对比 → 末段逐人入场并重复试验。

## 片段分工

### 先问清楚：你在找哪一种相同？

- 稳定 ID：birthday-pairs
- 位置：birthday-p1
- 形式：experience

表达任务：两种事件的比较对象必须可见；把指数式增长的配对连线与理论概率同时展示。

放在这里的理由：紧接对应原文：我们经常把问题理解成“有没有人和我同一天生日”，但真正的问题是“任意两个人”。随着人越来越多，可比较的两两组合增加得比人数快得多。

操作与反馈：点其他人与我，密网变成从你出发的星形；改变人数核对配对数与概率。

实现约定：独立沙箱内 HTML、CSS 与 SVG；共享状态只经 world 协议。

验收：

- #me → 23人 · 22组候选配对 · 概率 5.86%
- #reset → 23人 · 253组候选配对 · 概率 50.73%

代码指纹：654b988ccf3edfda246f3d78e795ac3b602cc623fdc5d03fe96e817df3e2821b

### 让生日真的走进房间

- 稳定 ID：birthday-room
- 位置：birthday-p2
- 形式：experience

表达任务：把随机单次与长期频率分开，碰撞以房间中两枚同色生日筹码显示。

放在这里的理由：紧接对应原文：这很适合做成一次小实验：让人一个一个走进房间，出现重复生日时停下来。重复几次，亲眼看看随机结果与理论概率的区别。

操作与反馈：逐人加入；或重复100次固定23人实验，观察频率接近而不必等于理论值。

实现约定：独立沙箱内 HTML、CSS 与 SVG；共享状态只经 world 协议。

验收：

- #add → 房间已有 1 人 · 尚无重复
- #reset → 房间已有 0 人 · 尚无重复

代码指纹：f89e46a2f16a046ef880846cfcb9a5daea39be32b6d3aa9751dc7cf5c78d269d
