# 三分钟演示与录屏脚本

本文件是待录制脚本。当前模型尚未配置，不能把它当成已录制的视频或已完成的演示。

## 开录前

- 模型连接和费用额度正常，至少三篇精选已经通过运行验收。
- 浏览器无痕窗口能打开最终公共域名；普通阅读不调用模型。
- 录屏只包含产品，隐藏配置、密钥、调试台和私人对话。
- 选好一篇可以在 60 秒左右完成修改的案例。记录真实时间，不把缓存冒充现场生成。

## 0:00–0:30：从回答开始

“有些内容，读懂不如自己试一次。”

打开知乎式问题页。操作轻交互，再操作一种明显不同的表达。保持正文与互动都在画面里。

## 0:30–0:50：提出一个改法

“作者也不需要知道代码怎么写。告诉 Agent，你想怎样表达。”

现场输入一个改变表达方向的要求，立即开始真实请求。不要只改颜色、字号或单个参数。

## 0:50–1:30：展示另一个世界

等待时切到已生成的另一篇回答，操作它并回放“此前加工过程”。解释：精选和现场结果都来自同一条加工链路，只是使用了不同档位的模型。

## 1:30–2:30：比较新表达

回到请求结果，直接操作新的交互。指出作者想法如何被重新表达，核对原文未被无关改写。

## 2:30–3:00：回到创作者

打开写回答入口，展示官方内容导入。

“我们让程序成为作者可以使用的一种内容语言。每篇回答，都能找到适合自己的表达。”

## 失败时

保留现场错误和上一版，说明本次调用没有成功。备用录屏必须明确标注“此前录制”，不要剪辑成一次成功的现场请求。

## 输出

完成后导出 1080p MP4，另存 15–30 秒短版。封面使用实际运行的代表案例，不使用开发者预先制作的场景来冒充 Agent 输出。视频文件与公开链接待真实录制后添加。
