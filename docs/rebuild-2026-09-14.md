## 通用实现

- 交互块增加可选 `mediaUrls` 和 `replaceParagraphIds`。媒体存入 `SourceAsset`，由 Runtime 注入校验过的图片；iframe 仍禁止联网。
- 只有图片成功解码且交互未报错时才折叠原图。媒体缺失、交互失败、只看原文时恢复；Studio、产品阅读页和离线包使用同一规则。
- 片段上限 24，讲解步骤上限 48，保留代码体积限制及按可见区域加载。外部核验链接也在宿主正文外提供可打开入口。
- `studio seed` 与 `studio clean` 默认预览，应用时校验版本。素材拆分精确迁移可定位备注，不可定位备注保留为待关联。
- `npm run baselines` 同步轻量阅读目录；原图按文章进入视口加载。首屏 JavaScript 856.37 kB（gzip 239.47 kB），相比内嵌全部图片时约 28 MB 明显减少。DLSS 原图包仍约 25.6 MB，未压缩或替换原件。
- 新增通用库条目 `image-comparison@1`、`discounted-cash-flow@1`、`aggregate-comparison@1`，各自保留版本、适用条件、来源产物和实际验收证据。宿主不按题材选择模板。
