# 真实加工链路

精选是 Agent 读取原文后生成、验收并保存的一组独立运行产物。宿主不按题材选择组件。用户最新明确要求“先使用自己来作为 agent 进行默认的生成”，因此允许当前 Codex 会话承担默认内容生成。

## 两条有明确来源的生产路径

AnswerSource → /api/generate → 已配置的模型 → 产物结构检查 → iframe 运行检查 → 最多一次修复 → AnswerArtifact。

API 离线制作脚本同样调用 /api/generate，使用 frontier 配置，保存真实结果与记录。线上默认使用 balanced 配置。

用户授权的会话路径：AnswerSource → 当前 Codex 会话读取及创作 → artifacts/session 原始代码产物 → record-session.ts → 同一结构检查与 iframe 运行检查 → 验收后保存为默认 AnswerArtifact。

会话产物记录 method=codex、tier=session。model 字段只写“Codex 当前会话（未记录具体模型 ID）”，不猜供应商模型名、不伪造 API 调用与 token 用量。网页只是读取并运行产物，不理解“相机”“火星”等题材。该路径不意味网页可以在无人操作时调用当前 Codex 会话。

## 内容资产

HTML、CSS、JavaScript、SVG、Canvas 视觉由受限的生成 Agent 读取文章后产生。当前默认产物由本会话完成，未使用图片工具或外部美术。此前的三张位图继续排除在产品之外。

若后续接入图片生成，必须成为产品 Agent 可调用的真实工具，记录工具输入与结果，并处理失败；不能把开发者的图片生成能力当作线上已有能力。

## 未配置模型时

可以阅读当前会话已经实际生成并验收的默认产物。未加工文章保留原文。在线生成入口解释配置状态；不返回假的新结果。单元测试的模拟模型响应不能充当实际产物或 API 模型质量评测。

## 整篇编排与设计基线

AnswerArtifact 的 blocks 是分布在稳定段落锚点的自由代码片段，最多 24 个，可用短行内表达、图示、体验、边注等间距语义。它不是组件树或题材模板。片段可以通过宿主声明的局部状态联动，不能读写其他回答。

新生成结果必须包含 design：整篇意图、阅读路线、语气、配色／字体／材质／动作约定，以及逐个片段的位置理由、操作、实现与验收要求。两档模型读取同一全局政策与当前文章基线。基线优先取当前产物；静态目录只在原文指纹吻合时使用。请求记录保存引用版本和指纹。

讲解默认手动，自动时每步至少 8 秒。scene 可以附带当前片段内的 click/input 演示，宿主校验边界、iframe 返回回执；错误与超时如实显示。说明是可公开复核的设计依据，不展示或伪造内部思维过程。详见 docs/baselines/README.md。
