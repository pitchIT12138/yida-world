## 已知边界

- 当前没有模型密钥，因此生成入口正确显示未连接状态，不返回伪造结果。
- 请求频率限制是单 Worker 实例级，不保证全局日预算或跨实例防重放。正式开放前须设置供应商硬预算；修复票据限制请求内容与原始截止时间。
- iframe 启动检查覆盖启动错误和短窗口异步错误，不覆盖所有操作路径或无限循环的硬终止。
- 本地开发服务已接入 SQLite 工作区（见下方更新）；当前 Worker 发布包尚未接入云端工作区，不自动上传个人草稿。
- 导入文件中的模型记录属于文件声明；原文指纹证明内容对应关系，不是第三方模型调用的独立认证。
